# School logos

Drop a school's logo file here named to match its slot in
`src/content/schools.ts`, e.g. `school-01.png`, `school-02.png`, ...
`school-21.png`.

Once the file exists, the Champion Schools carousel automatically swaps
that slot's placeholder box for the real logo — no component changes
needed. Just also fill in the matching `alt` text in `schools.ts`.
